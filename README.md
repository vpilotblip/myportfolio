# Sai Varshini — Portfolio

A responsive React + Vite portfolio inspired by the screenshots you shared.

## Requirements
- Node.js (current LTS version)
- npm

## Run locally
1. Extract this ZIP folder.
2. Open the extracted folder in VS Code.
3. Open the terminal in VS Code.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Personalize before publishing
- In `src/main.jsx`, update the sample email `your.email@example.com`.
- Replace `https://www.linkedin.com/` with your LinkedIn profile URL.
- Add your actual GitHub and project links where appropriate.
- Review skills and credentials so they reflect your real experience.
- Update project descriptions and add links to live demos/source repositories when available.

## Build for deployment
Run `npm run build`. Vite creates a `dist` folder that can be deployed to services such as Netlify or Vercel.

This is a frontend-only portfolio. The email button copies the configured email address; the LinkedIn button opens the LinkedIn website. A backend is not required for this version.
